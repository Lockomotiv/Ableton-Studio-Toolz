Schnellstart Testversion

Version 0.3.0 · Windows 11 · Ableton Live 12 Suite
Dauer: ca. 15 Minuten
Testversion: Diese Version ist automatisch getestet, aber noch nie mit echtem Ableton Live unter Windows gelaufen. Bitte mit einem Test-Set arbeiten, nicht mit Ihrem Arbeitsprojekt – Connect Studio verändert Tempo, Loop, Lautstärke und Panorama.

1Installieren

  1. Datei LOCK-O-MOTIV Connect Studio_0.3.0_x64-setup.exe aus dem Download-Paket starten.
  2. Optional Prüfsumme kontrollieren (PowerShell im Ordner): Get-FileHash *setup.exe → muss mit der .sha256-Datei übereinstimmen.
  3. Windows SmartScreen warnt, weil die Testversion nicht signiert ist: Weitere Informationen → Trotzdem ausführen.
  4. Installation läuft pro Benutzer, ohne Administratorrechte. Danach Connect Studio über Startmenü oder Desktop öffnen.

4Zu zweit testen (zwei Windows-Rechner im selben Netz)

Rechner A – Host (mit Ableton)

  1. Seite Session: Remote Studio, „Lokales Netz“, neues Projekt „Test“ → Sitzung starten.
  2. Einladungscode LOM1.… kopieren und an B schicken (Messenger/E-Mail).
  3. Nach dem Verbinden: Sicherheitscode mit B vergleichen.
  4. „Bildschirm + DAW-Ton“ → Bildschirm wählen, „Systemaudio teilen“ an.
  5. Anfrage von B: „Gemeinsam steuern“, später „Komplett übergeben“ und „Zurückholen“.

Rechner B – Gast

  1. Einrichtung mit Rolle „Gast“ (Schritt 2/3 darf ohne Ableton übersprungen werden).
  2. Seite Session: Code einfügen → Beitreten, Kamera/Mikro erlauben.
  3. Seite Studio: gesperrt → „Steuerung anfragen“; nach Freigabe Play/Tempo/Fader bedienen.
  4. Eine WAV aus dem Explorer ins Fenster ziehen.
  5. Seite Projekt-Hub: Idee festhalten.

5Lokal mit Ableton Link

Beide Rechner im selben Netz, jeder mit eigenem Live: auf beiden Studio → 🔗 Link an. Tempo und Phase laufen sample-genau synchron (Ableton-eigene Funktion). Optional zusätzlich eine Session im Modus Dual Studio für Video, Hub und Samples.

7Wenn etwas hakt

SymptomLösung
„Keine Antwort von AbletonOSC (Timeout)“Live nach der Installation neu gestartet? Control Surface = AbletonOSC? Ordnername exakt AbletonOSC?
„UDP-Port 127.0.0.1:11001 … belegt“Zweite Connect-Studio-Instanz oder anderes OSC-Programm beenden.
Script „nicht gefunden“ / falsche User LibraryOrt in Live ablesen (Einstellungen → Library → Speicherort der User Library), in Connect Studio unter Einrichtung → Schritt 2 oder Einstellungen per „Ordner wählen …“ setzen, dann neu installieren.
Gast kann nicht beitretenFirewall-Abfrage bei A mit „Privat“ erlaubt? Beide im selben Netz? Einladung abgelaufen (Standard 24 h)?
Kein DAW-Ton beim Gast„Systemaudio teilen“ im Freigabedialog an? Live gibt über ASIO ohne Windows-Ausgang aus → im Interface-Treiber Loopback aktivieren oder Live auf ein Windows-Gerät stellen.
